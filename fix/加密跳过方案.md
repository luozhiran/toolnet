# 加密跳过方案 —— 指定接口不加密

## 背景

开启了全局字段加密后，所有 JSON/Form 请求都会经过 `EncryptInterceptor` 处理。但实际场景中，某些接口不需要加密：

- `/health-check` — 健康检查
- `/public/*` — 公开接口（无敏感数据）
- `/upload/*` — 文件上传（二进制 body 本就不会被处理）
- `/third-party/*` — 第三方回调接口（服务器不识别加密格式）
- 登录接口 — 此时还没有 SessionKey

需要提供一套灵活的跳过机制，从**配置级别**和**请求级别**两个维度控制。

---

## 方案设计

### 维度一：配置级跳过（EncryptConfig）

在 `encrypt { }` 中声明全局跳过规则，适用于已知的、固定的不需要加密的接口：

```kotlin
Net.instance.configure {
    encrypt {
        algorithm(Algorithm.AES_GCM_NO_PADDING)
        secretKey(sessionKey)
        iv(sessionIv)
        encryptField("phone")
        encryptField("password")

        // 跳过不需要加密的接口
        skipPath(Regex("/health-check"))
        skipPath(Regex("/public/.*"))
        skipPath(Regex("/upload/.*"))
        skipPath(Regex("/third-party/.*"))
    }
}
```

**实现**：`EncryptConfig` 新增 `skipPaths` 列表，`EncryptInterceptor` 在 `encryptRequest()` / `decryptResponse()` 入口处先检查当前请求路径是否匹配任一跳过规则，命中则直接透传原始请求。

### 维度二：请求级跳过（Header / Tag）

对于临时性、不确定的跳过需求，由单个请求自行控制：

```kotlin
// 方式 A：标记跳过（推荐）
Net.instance.postJson()
    .url("https://api.example.com/special-api")
    .addParam("data", "value")
    .skipEncrypt()                       // ← 跳过加密
    .send(callback)

// 方式 B：对 Flow 同样生效
Net.instance.get()
    .url("https://api.example.com/legacy-data")
    .skipEncrypt()
    .flowString()
    .collect { body -> /* body 中的字段不会被解密 */ }
```

**实现**：在 `ParamsBuilder` 上新增 `skipEncrypt()` 方法，内部设置一个 OkHttp Tag（`EncryptInterceptor.SKIP_TAG → true`）。`EncryptInterceptor` 在入口处检查此 Tag，命中则透传。

## 需要新增/改动的代码

### 新增：EncryptConfig.skipPath()

**文件**: `EncryptConfig.kt`，新增属性和 DSL 方法：

```kotlin
// 属性
val skipPaths: MutableList<Regex> = mutableListOf()

// DSL 方法
fun skipPath(pattern: Regex): EncryptConfig {
    skipPaths.add(pattern)
    return this
}
```

### 新增：ParamsBuilder.skipEncrypt()

**文件**: `ParamsBuilder.kt`，新增方法：

```kotlin
fun skipEncrypt(): ParamsBuilder {
    // 通过 OkHttp Tag 机制标记，不影响请求体
    tag(EncryptInterceptor.SKIP_TAG)
    return this
}
```

> 说明：利用已有的 `tag()` 方法设置 `EncryptInterceptor.SKIP_TAG` 常量，无需新增属性。Tag 是 OkHttp 原生机制，Request 级别的元数据，不发送到服务器。

### 改动：EncryptInterceptor —— 入口加跳过检查

**文件**: `EncryptInterceptor.kt`，在 `intercept()` 方法最前面增加判断：

```kotlin
override fun intercept(chain: Interceptor.Chain): Response {
    val request = chain.request()

    // 检查是否跳过加密
    if (shouldSkip(request)) {
        return chain.proceed(request)  // 直接透传
    }
    // ... 原有加密逻辑
}

private fun shouldSkip(request: Request): Boolean {
    // 1. 请求级：检查 Tag
    if (request.tag() == SKIP_TAG) return true

    // 2. 配置级：检查路径匹配
    val path = request.url.encodedPath
    for (pattern in config.skipPaths) {
        if (pattern.matches(path)) return true
    }

    return false
}

companion object {
    const val SKIP_TAG = "__encrypt_skip__"
}
```

### 改动：EncryptConfig —— 配置表增加

**文件**: `NetConfig.kt` 的 `encrypt` DSL 闭包中支持 `skipPath`。

## 完整使用示例

```kotlin
// Application 初始化时一次性配置
Net.instance.configure {
    encrypt {
        algorithm(Algorithm.AES_GCM_NO_PADDING)
        secretKey(sessionKey)
        iv(sessionIv)

        // ===== 全局跳过规则 =====
        skipPath(Regex("/health-check"))
        skipPath(Regex("/public/.*"))
        skipPath(Regex("/upload/.*"))

        // ===== 需要加密的字段 =====
        encryptField("phone")
        encryptField("password")
        encryptField("idCard")
    }
}

// ===== 业务代码 =====

// 普通请求 —— 自动加密
Net.instance.postJson()
    .url("https://api.example.com/user/update")
    .addParam("phone", "13800138000")     // ✅ 自动加密
    .addParam("name", "张三")              // 不加密
    .send(callback)

// 公开接口 —— 配置级跳过（/public/ 开头的全部跳过）
Net.instance.get()
    .url("https://api.example.com/public/news")
    .send(callback)                        // ✅ 全局规则命中，自动跳过

// 特殊接口 —— 请求级跳过
Net.instance.postJson()
    .url("https://api.example.com/legacy-login")
    .addParam("password", "123456")        // ❌ 不加密，明文传输
    .skipEncrypt()                         // ← 请求级跳过
    .send(callback)

// Retrofit Service 同样生效
interface UserService {
    @POST("user/login")
    suspend fun login(@Body req: LoginRequest): LoginResponse  // ✅ 自动加密

    @GET("public/news")
    suspend fun getNews(): NewsList  // ✅ 全局规则 /public/.* 命中，自动跳过
}
```

## 跳过判断流程

```
请求进入 EncryptInterceptor
    │
    ├── request.tag() == SKIP_TAG ?
    │       └── YES → 跳过（请求级）
    │
    ├── request.url.path 匹配 skipPaths 中任一正则 ?
    │       └── YES → 跳过（配置级）
    │
    ├── request.method == GET && skipGetRequest == true ?
    │       └── YES → 跳过（GET 无 body）
    │
    ├── body.contentType 非 JSON/Form ?
    │       └── YES → 跳过（二进制/文件）
    │
    └── 以上都不满足 → 执行加解密
```

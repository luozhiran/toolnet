# 加密完整方案 —— 全局配置 + 单请求控制 + 优先级

## 设计目标

覆盖四种业务场景，且**单请求控制优先级最高**：

| 场景 | 全局策略 | 单请求例外 |
|---|---|---|
| A | 全站加密 | 个别请求跳过 |
| B | 全站不加密 | 个别请求加密 |
| C | 指定路径加密（OPT_IN） | 个别路径内请求跳过 |
| D | 指定路径跳过（OPT_OUT） | 个别跳过路径内请求加密 |

---

## 优先级链

```
┌──────────────────────────────────────────────┐
│  请求级控制（最高优先级）                       │
│  ├── .encrypt()      强制加密，无视全局跳过     │
│  └── .skipEncrypt()  强制跳过，无视全局加密     │
├──────────────────────────────────────────────┤
│  全局模式（中间优先级）                         │
│  ├── OPT_OUT  全量加密，skipPath 排除          │
│  └── OPT_IN   全量跳过，encryptPath 纳入       │
├──────────────────────────────────────────────┤
│  全局规则（基础层）                             │
│  ├── encryptField() / encryptPattern()        │
│  ├── encryptPath()                            │
│  └── skipPath()                               │
└──────────────────────────────────────────────┘
```

**规则**：上层命中即短路，不再检查下层。

## API 设计

### 全局配置（EncryptConfig DSL）

```kotlin
Net.instance.configure {
    encrypt {

        // ===== 1. 模式 =====
        encryptMode(EncryptMode.OPT_OUT)    // OPT_OUT（默认）| OPT_IN

        // ===== 2. 算法与密钥 =====
        algorithm(Algorithm.AES_GCM_NO_PADDING)
        secretKey(sessionKey)
        iv(sessionIv)

        // ===== 3. 字段规则 =====
        encryptField("password")            // 全局字段：双向加密
        decryptField("realName")            // 全局字段：仅响应解密
        encryptPattern(Regex(".*[Ss]ecret"))

        // ===== 4. 路径规则 =====
        encryptPath(Regex("/user/.*"), listOf("phone", "email"))
        encryptPath(Regex("/payment/.*"), listOf("bankCard", "cvv"))

        // ===== 5. 跳过规则（OPT_OUT 下生效）=====
        skipPath(Regex("/public/.*"))
        skipPath(Regex("/health-check"))

        // ===== 6. 开关 =====
        requestEncrypt(true)
        responseDecrypt(true)
        skipGetRequest(true)
    }
}
```

### 单请求控制（ParamsBuilder 扩展）

```kotlin
// 强制加密：无视全局跳过规则
Net.instance.postJson()
    .url("https://api.example.com/public/report")   // ← 全局 skipPath 本应跳过
    .addParam("phone", "13800138000")
    .encrypt()                                       // ← 单请求强制加密，优先级最高
    .send(callback)

// 强制跳过：无视全局加密规则
Net.instance.postJson()
    .url("https://api.example.com/user/login")       // ← 全局本应加密
    .addParam("password", "123456")
    .skipEncrypt()                                   // ← 单请求强制跳过
    .send(callback)
```

> `encrypt()` 和 `skipEncrypt()` 不能同时调用（后者覆盖前者）。

## 四种场景完整示例

### 场景 A：全站加密 + 个别跳过

```kotlin
// 全局配置
encrypt {
    encryptMode(EncryptMode.OPT_OUT)
    encryptField("password")
    encryptField("phone")
    skipPath(Regex("/public/.*"))
}

// 正常请求 → 自动加密
Net.instance.postJson()
    .url("https://api.example.com/user/login")
    .addParam("password", "123456")
    .send(callback)  // ✅ password 加密

// 全局跳过的接口 → 自动跳过
Net.instance.get()
    .url("https://api.example.com/public/news")
    .send(callback)  // ✅ 全局 skipPath 命中，跳过

// 特例：全局跳过接口中的某个请求需要加密
Net.instance.postJson()
    .url("https://api.example.com/public/feedback")
    .addParam("phone", "13800138000")
    .encrypt()       // ← 单请求强制加密，优先级 > skipPath
    .send(callback)  // ✅ phone 加密
```

### 场景 B：全站不加密 + 个别加密

```kotlin
// 全局配置
encrypt {
    encryptMode(EncryptMode.OPT_IN)
    encryptPath(Regex("/user/login"), listOf("password"))
}

// 正常请求 → 自动跳过
Net.instance.get()
    .url("https://api.example.com/news/list")
    .send(callback)  // ✅ 零开销透传

// 全局加密接口 → 自动加密
Net.instance.postJson()
    .url("https://api.example.com/user/login")
    .addParam("password", "123456")
    .send(callback)  // ✅ password 加密

// 特例：全局不加密的接口中某个请求需要加密
Net.instance.postJson()
    .url("https://api.example.com/news/comment")
    .addParam("phone", "13800138000")       // ← 本接口不在 encryptPath 中
    .encrypt()                               // ← 单请求强制加密
    .send(callback)  // ✅ phone 加密（全局所有 encryptField 规则对此请求生效）
```

### 场景 C：OPT_IN 模式 + 路径内个别跳过

```kotlin
// 全局配置
encrypt {
    encryptMode(EncryptMode.OPT_IN)
    encryptPath(Regex("/user/.*"), listOf("phone", "email", "idCard"))
}

// /user/* 接口 → 自动加密
Net.instance.postJson()
    .url("https://api.example.com/user/profile")
    .addParam("phone", "13800138000")
    .addParam("email", "test@test.com")
    .send(callback)  // ✅ phone, email 加密

// 特例：/user/* 路径内某个请求不需要加密
Net.instance.postJson()
    .url("https://api.example.com/user/search")   // ← 匹配 /user/*
    .addParam("phone", "13800138000")
    .skipEncrypt()                                  // ← 单请求强制跳过
    .send(callback)  // ✅ phone 明文
```

### 场景 D：OPT_OUT 模式 + 跳过路径内个别加密

```kotlin
// 全局配置
encrypt {
    encryptMode(EncryptMode.OPT_OUT)
    encryptField("password")
    skipPath(Regex("/public/.*"))
}

// /public/* 接口 → 自动跳过
Net.instance.get()
    .url("https://api.example.com/public/announcement")
    .send(callback)  // ✅ 跳过

// 特例：/public/* 内某个请求需要加密
Net.instance.postJson()
    .url("https://api.example.com/public/apply")
    .addParam("password", "123456")
    .encrypt()       // ← 单请求强制加密，优先级 > skipPath
    .send(callback)  // ✅ password 加密
```

## 判断流程图

```
请求进入 EncryptInterceptor
    │
    ├── request.tag == ENCRYPT_TAG ?
    │       └── YES → 强制执行加密（最高优先级）
    │
    ├── request.tag == SKIP_TAG ?
    │       └── YES → 强制跳过（最高优先级）
    │
    ├── EncryptMode == OPT_IN ?
    │       └── YES → 仅当路径匹配 encryptPath 规则时才加密
    │
    ├── EncryptMode == OPT_OUT ?
    │       └── YES → 路径不匹配 skipPath 就加密
    │
    ├── GET && skipGetRequest ?
    │       └── YES → 跳过
    │
    ├── Content-Type 非 JSON/Form ?
    │       └── YES → 跳过
    │
    └── 执行加解密
```

## 实现设计

### EncryptMode 枚举（新增）

```kotlin
enum class EncryptMode {
    /** 全量加密 —— encryptField 全局生效，skipPath 排除 */
    OPT_OUT,

    /** 按需加密 —— 仅 encryptPath 匹配的路径生效，其余透传 */
    OPT_IN
}
```

### EncryptConfig 新增内容

```kotlin
class EncryptConfig {
    // 现有属性保持不变 ...

    /** 加密模式，默认 OPT_OUT（向后兼容） */
    var encryptMode: EncryptMode = EncryptMode.OPT_OUT

    /** 跳过路径列表（OPT_OUT 模式生效） */
    val skipPaths: MutableList<Regex> = mutableListOf()

    // ==== 新增 DSL 方法 ====

    fun encryptMode(mode: EncryptMode): EncryptConfig { ... }
    fun skipPath(pattern: Regex): EncryptConfig { ... }
}
```

### ParamsBuilder 新增方法

```kotlin
abstract class ParamsBuilder : Builder, SentBuilder {

    /**
     * 强制加密当前请求
     *
     * 优先级最高，覆盖全局 skipPath 和 OPT_IN 模式下的默认跳过行为。
     * 调用后当前请求的所有字段规则（encryptField / encryptPath / encryptPattern）都会生效。
     */
    fun encrypt(): ParamsBuilder {
        tag(EncryptInterceptor.ENCRYPT_TAG)
        return this
    }

    /**
     * 强制跳过当前请求的加解密
     *
     * 优先级最高，覆盖全局所有加密规则（encryptField / encryptPath / encryptPattern）。
     * 调用后当前请求完全不经过加解密处理，直接透传。
     */
    fun skipEncrypt(): ParamsBuilder {
        tag(EncryptInterceptor.SKIP_TAG)
        return this
    }
}
```

> 利用已有的 `tag()` 方法设置 OkHttp Tag，零侵入。

### EncryptInterceptor 核心判断

```kotlin
class EncryptInterceptor(private val config: EncryptConfig) : Interceptor {

    companion object {
        const val ENCRYPT_TAG = "__encrypt_force__"
        const val SKIP_TAG   = "__encrypt_skip__"
    }

    override fun intercept(chain: Interceptor.Chain): Response {
        var request = chain.request()

        if (config.requestEncryptEnabled && config.hasValidConfig()) {
            if (shouldEncrypt(request)) {
                request = encryptRequest(request)
            }
        }

        val response = chain.proceed(request)

        if (config.responseDecryptEnabled && config.hasValidConfig()) {
            if (shouldDecrypt(response)) {
                return decryptResponse(response)
            }
        }

        return response
    }

    private fun shouldEncrypt(request: Request): Boolean {
        // 1. 最高优先级：请求级强制加密
        if (request.tag() == ENCRYPT_TAG) return true

        // 2. 最高优先级：请求级强制跳过
        if (request.tag() == SKIP_TAG) return false

        // 3. GET 跳过
        if (config.skipGetRequest && request.method == "GET") return false

        // 4. 非文本 body 跳过
        val contentType = request.body?.contentType() ?: return false
        if (!contentType.subtype.contains("json", ignoreCase = true) &&
            !contentType.subtype.contains("x-www-form-urlencoded", ignoreCase = true)) {
            return false
        }

        val path = request.url.encodedPath

        // 5. 全局模式
        return when (config.encryptMode) {
            EncryptMode.OPT_IN  -> matchesAnyEncryptPath(path)
            EncryptMode.OPT_OUT -> !matchesAnySkipPath(path)
        }
    }
}
```
